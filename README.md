# Anton

Local SLM-based multi-agent system for generating theatre plays.

## Requirements

Python 3.11 or newer.

## Run

From the repository root:

```sh
python3 src/anton/main.py
```

Expected output:

```text
Anton initialized.
```

## Project structure

- `src/anton/`: Python package and application entry point.
- `tests/`: Reserved for future tests.

## Status

Minimal project setup. No external dependencies are required.
